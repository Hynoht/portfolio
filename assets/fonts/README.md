# Polices

Polices variables auto-hébergées (aucune requête tierce, compatible avec la CSP `font-src 'self'`) :

- `jost-var.woff2` — Jost, graisses 300 à 700, titres
- `inter-var.woff2` — Inter, graisses 300 à 700, texte courant

Sous-ensemble latin, licence SIL Open Font License 1.1, récupérées via Fontsource
(`@fontsource-variable/jost`, `@fontsource-variable/inter`). Déclarations dans `css/fonts.css`.
